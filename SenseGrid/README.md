# Sense Grid
# Проект для учёбы "Устройство собирающее информацию об окружающем пространстве с программируемыми выводами"
# Основная идея
1. Плата ESP32-C3 собирает с датчиков информацию
    - 1. Модуль датчика газа SCD41
        - CO2
    - 2. Метеодатчик BME280
        - Температура
        - Влажность
        - Атмосферное давление
    - 3. Как вариант выносной датчик температуры **DS18B20** [полезно](https://alexgyver.ru/lessons/ds18b20/), чтобы мерить не у прибора, а была возможность вынести этот дачик например 15м от прибора ( в погреб как вариант). Можно протянуть 15–20 м без потерь
    - 4. Сделать возможность подключать несколько выносных датчиков температуры 
    - 5. Датчик освещенности
        - Освещение окружающей среды
2. По запраграммированной в ней логике (todo: мб как-то извне программировать) включает 220 вольт на вывовах
    - 1. К294КП7ВП1, Реле твердотельное оптоэлектронное ±400В/1.8Ом
        - Реле для коммутации 220 вольт, мощностью до 220 Ват.
        - Управлять релюшкой логическим уровнем от ESP32-C3 , который состолвяет 3.3в
3. E-lnk экран 🖥️ !
    - 1. Общается через SPI
    - 2. Возможные библиотеки, которые помогут **Adafruit_GFX + Adafruit_EPD**
    - 3. как вариант его[тык](https://aliexpress.ru/item/1005004644515880.html?sku_id=12000034319637607&spm=a2g2w.productlist.search_results.0.6949f993l9mJvE)
    - 4. WeAct дешёво и сердитая линейка на алике
4. Корпус на 3Д-принтере
    - 1. Сделать впадину с креплением для E Ink экрана(Экран для чтения, мало тока ест) 
    - 2. Ввод для подключения 220 вольт для работы запрограммированых выводов, без подключания к 220в, эта фича работать не будет
    - 3. Посадку под аккумуляторную батарейку 9в (как в часах)
    - 4. Мб какой-нибудь красивое Hi-TEC оформление
    - 5. Мб какую-нибудь вентиляцию продумать, ведь реле будут греться, а пластик не особа любит когда его греют

5. Требования к плате
    - 1. Разделить высоковольтную 220вольт и низковольтную 3.3в часть
    - 2. Предохранитель ампера на 3 А, в зависимости от того, скок получиться впихнуть релюшек
    - 3. Мб гальванически развязаться 
    - 4. Мб защиту от скачков напряжения, оно ведь типа для гараж, а там не стабильный свет ( Варистр )
    - 5. Вздохновившись прошлым проектом часов, надо сделать, что при наличии 220 вольт, заряжать 9 вольтовый аккумулятор батарейку 
    - 6. Понижайку с 9 вольт на 5 вольт
    - 7. Добавить USB мб

6. Программирование извне
    - 1. пощупать технолоджи в виде OTA + Web-интерфейс
        - Через OTA можно обновлять прошивку по Wi-Fi без проводов
        - Web-интерфейс какая-нибудь простая страничка на ESP32
        - ### Что можно настроить
            - Пороги СО2 (вкл\выкл реле) для включения вытяжки
            - Расписание (например выкл свет с 18 до 6)
            - Имена датчиков (Garage, Pogreb)
            - Обновление экрана E-lnk который ( раз 1/5/10/15 мин)
7. Интерпретатор.
   - 1. Перспективно посмотреть МК от 2 ядер
     2. одно ядро выполняет скомпилированный код
     3. Второе ядро получаает интерпритируемый язык ( код ) и выполняет его.
     4. Надо подумать в жтом направлении прям хорошо
